# Statement font

`IBMPlexSansArabic-Regular.ttf` is the complete IBM Plex Sans Arabic Regular face used for sample PDFs. The website already uses this font family. The complete face preserves Arabic shaping, punctuation and symbols that are absent from the web Arabic subset. SAR figures and numeric dates are rendered separately with the existing Inter font.

Downloaded with verified HTTPS from the Google Fonts repository:

- [Font source](https://github.com/google/fonts/blob/main/ofl/ibmplexsansarabic/IBMPlexSansArabic-Regular.ttf)
- [Original SIL Open Font License](https://github.com/google/fonts/blob/main/ofl/ibmplexsansarabic/OFL.txt), retained in `OFL.txt`.
- SHA-256: `6f611412270a132bbac838da9259d4c68569b4175f3b3b8fa3fa36a30b56dab9`.

The font is unmodified. The statement route traces this file into deployments; it never fetches fonts or sends client data to a font service at runtime.
